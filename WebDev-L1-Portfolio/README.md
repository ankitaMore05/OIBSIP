# Personal Portfolio

Oasis Infobyte SIP | Web Development & Designing | Level 1, Task 2

A personal portfolio website: profile, about, skills, projects and contact.

## Tech
HTML5 and CSS3 (no JavaScript needed).

## Features
- Hero with name, role title and avatar placeholder (initials)
- About section, skills grid, 2 project cards with GitHub link placeholders
- Contact section with email, LinkedIn and GitHub links
- Smooth scroll navigation (`scroll-behavior: smooth`)
- Consistent colour palette and fonts (Sora + Inter)
- Fully responsive with Flexbox and CSS Grid

## Run
Open `index.html` in a browser.
