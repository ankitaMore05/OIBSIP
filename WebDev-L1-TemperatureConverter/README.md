# Temperature Converter

Oasis Infobyte SIP | Web Development & Designing | Level 1, Task 3

An interactive tool that converts between Celsius, Fahrenheit and Kelvin.

## Tech
HTML5, CSS3, vanilla JavaScript.

## Features
- Numeric input with validation (non-numeric input shows an error message)
- Unit selector (Celsius / Fahrenheit / Kelvin)
- Convert button (Enter key also works)
- Result area shows all three units at once
- Absolute-zero check with a friendly message
- Centred, clean layout

## Formulas
- C to F: C x 9/5 + 32
- F to C: (F - 32) x 5/9
- C to K: C + 273.15

## Run
Open `index.html` in a browser.
