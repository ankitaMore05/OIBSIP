# To-Do Web App
Oasis Infobyte SIP | Web Development & Designing | Level 2, Task 3

## Features
- Add tasks; they appear in the Pending list
- Mark Complete moves a task to Completed (Undo moves it back)
- Inline Edit (Enter to save, Esc to cancel) and Delete
- Counters: "X pending" and "Y completed"
- Bonus: added/completed timestamps
- Bonus: tasks persist after refresh using localStorage
- Friendly empty-state messages

## Run
Open `index.html` in a browser.
