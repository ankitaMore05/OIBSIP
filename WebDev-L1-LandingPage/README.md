# Landing Page: Spoke Mobile Bike Repair

Oasis Infobyte SIP | Web Development & Designing | Level 1, Task 1

A static landing page for a fictional mobile bike-repair service.

## Tech
HTML5 and CSS3 only (no JavaScript).

## Features
- Sticky navigation bar with 4 links
- Hero with headline, subheadline and call-to-action button
- Three content sections: Services, How it works, Reviews
- Footer with placeholder contact and social links
- Single colour palette (navy, yellow, sky blue) set as CSS variables
- Responsive layout using Flexbox and CSS Grid
- Explicit `box-sizing`, padding and margins to prevent overlap
- Two type sizes: heading font (Bricolage Grotesque) and body font (DM Sans)

## Run
Open `index.html` in any browser.
