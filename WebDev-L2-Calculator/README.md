# Calculator
Oasis Infobyte SIP | Web Development & Designing | Level 2, Task 1

Browser calculator built with HTML, CSS Grid and vanilla JavaScript.

## Features
- Display, digits 0-9, decimal point
- Operators: + - x /
- Equals, Clear (C), Backspace
- Division by zero shows an error message instead of crashing
- Operator chaining: 5 + 3 x 2 = 16 (operations are applied one at a time, like a basic pocket calculator)
- Buttons laid out with CSS Grid
- Event listeners on all buttons (no inline onclick), and no eval()

## Run
Open `index.html` in a browser.
